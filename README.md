# 7788 游戏服务器网站

面向朋友开放的 Terraria 与 Minecraft 私人服务器入口，包含玩法介绍、进服教程、更新记录和公开状态页。

## 当前内容

- 首页宣传、两个世界摘要和进服流程；
- Terraria 探索战斗服介绍与四步进服教程；
- Minecraft 冒险生存服介绍与四步进服教程；
- 两个世界的完整模组列表；
- 使用明确演示标识的服务器状态页；
- 玩家可见更新记录。

网站不会公开密码、SSH、内网地址、认证码或管理日志。真实状态采集尚未连接游戏 VPS。

## 本地开发

需要 Node.js 22 或更新版本。

Windows 上可直接双击项目根目录中的 `打开本地预览.cmd`。启动器会检查现有预览、首次安装依赖、启动本地服务并打开浏览器。

```powershell
npm install
npm run dev
npm run build
```

关闭标题为 `7788 Local Preview` 的 PowerShell 窗口即可停止预览。
